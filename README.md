# 机器人与具身智能资料库

[打开阅读网页](https://zarek1115.github.io/robotics-library/)

这是我持续学习机器人与具身智能行业时整理的资料库。我希望先弄清楚机器人在解决什么问题、应用需要哪些条件，再理解技术进展如何影响产业发展。资料按研究问题、入门阅读和核心材料组织，方便在阅读中比较不同解释，而不只追踪产品发布和市场预测。

## 关注的问题

- 具身智能解决了哪些实际问题，真实需求如何形成？
- 从技术进展到规模化应用，还需要跨过哪些关口？
- 行业处于怎样的发展阶段，未来可能沿哪些路径演进？
- 产业链如何分工，竞争优势和价值将在哪里形成？
- 中国与海外的发展路径和产业格局有哪些差异？
- 哪些证据支持当前判断，哪些变化会促使我们修正判断？

阅读时，我关注报告之间的定义、数据年份、样本和测算假设是否一致，也关注与原有判断相反的依据。希望逐步形成能说明依据、适用条件和更新理由的行业认识。

## 从哪里开始

第一次访问可以从[入门阅读](https://zarek1115.github.io/robotics-library/#view=intro)开始，再到[核心材料](https://zarek1115.github.io/robotics-library/#view=library&pool=core)按问题选择。全部材料可按题名、机构、年份和专题标签查找；卡片的“打开原文”和“详情”分别提供现有材料与阅读说明。

截至2026年10月27日，目录有3353条记录，其中69条核心材料、9份入门阅读安排。目录同时保留必要的来源与历史记录，记录数量不等同于独立完整报告数量。核心是后续集中阅读的选择，入门阅读包含在核心中；摘要、节选和目录介绍按现有内容标注，可在[待获取](https://zarek1115.github.io/robotics-library/#view=acquire)集中查看。

目前的工作重心是阅读、比较和积累判断。资料分类、核心选择和阅读安排会随认识深化继续调整。

## 网页与维护

本仓库保存可直接运行的阅读网页。下载后可在浏览器打开 `index.html`；在线原件由现有文件服务提供，报告保留原作者与机构署名。

维护时以本地资料库为主，导出同一份公开目录更新网页。仅修改题名、标签或阅读说明时，更新网页即可；原件新增或更换时，再同步对应文件。个人阅读反馈和本机管理功能保留在本地。
